Voir le site
------------
Double-cliquez sur index.html : il s'ouvre dans votre navigateur.
Une connexion internet est nécessaire pour les polices (Cormorant Garamond, Manrope).

Mettre en ligne
---------------
Envoyez le dossier complet (index.html + css + js + assets) à la racine de votre
hébergement (FTP, cPanel, Netlify, Vercel, GitHub Pages...). Aucun serveur ni base
de données n'est nécessaire.

Sur Vercel :
- Application Preset : Other ; laisser Build Command et Output Directory vides.
- Root Directory : le dossier qui contient index.html (./ s'il est à la racine du dépôt,
  sinon le nom du sous-dossier, par exemple tca-site).
- Nom du projet en minuscules (ex. tca-advisory) : il donne l'adresse tca-advisory.vercel.app.
- Aucun réglage d'environnement : le formulaire passe par WhatsApp, sans serveur.
- Le plan gratuit Hobby de Vercel est réservé à un usage personnel non commercial ;
  un site d'entreprise relève du plan Pro (payant) ou d'un autre hébergeur.

  publication, durée de conservation, n° de déclaration CNDP) ; faire valider par votre conseil

Référencement (SEO) : quand le domaine est choisi
-------------------------------------------------
Remplacer « https://www.votre-domaine.ma » par le vrai domaine dans :
- index.html et digital.html : bloc commenté « Domaine définitif » en haut de la page
  (supprimer <!-- et --> autour des lignes canonical et og:url pour les activer)
- index.html et digital.html : og:image → adresse complète, ex.
  https://www.tca-advisory.ma/assets/img/partage-tca.jpg (partage-digital.jpg pour digital.html)
- sitemap.xml (2 adresses) et robots.txt (ligne Sitemap, retirer le #)
Puis : créer la propriété dans Google Search Console, y déclarer sitemap.xml,
et créer la fiche Google Business Profile (adresse, téléphone, horaires, lien du site).

Réglages utiles
---------------
- Numéro WhatsApp : en haut de js/main.js (WHATSAPP = '212668173299')
- Messages WhatsApp pré-remplis (y compris ceux de TCA Digital) : MESSAGES dans js/main.js
- Seuil d'endettement du simulateur : SEUIL_ENDETTEMENT = 0.40 dans js/main.js
- Couleurs : variables --noir, --or, --beige, --brun... en haut de css/styles.css
- Titre Google et description : balises <title> et <meta name="description"> en haut
  de chaque page (titre ≤ 60 caractères, description ≤ 160)
- Données structurées (fiche entreprise + FAQ pour Google) : bloc application/ld+json en
  haut de index.html. Si vous modifiez une question de la FAQ, modifiez-la aussi dans ce bloc.

Formulaire de contact : WhatsApp
--------------------------------
Le formulaire n'utilise aucun serveur. Quand le client clique sur « Envoyer ma demande
sur WhatsApp », WhatsApp s'ouvre avec sa demande pré-remplie (nom, téléphone, projet,
montant, ville, message) adressée au 06 68 17 32 99 ; il lui reste à appuyer sur Envoyer.
Si WhatsApp ne s'ouvre pas, un lien de secours et le numéro de téléphone s'affichent.
Limite : si le client n'appuie pas sur Envoyer dans WhatsApp, vous ne recevez rien.
Le consentement (loi 09-08) reste obligatoire avant l'ouverture de WhatsApp.

Menu, pied de page et pages services
------------------------------------
Les 7 pages TCA Advisory (accueil + 5 pages services + simulateur) ont le même menu et le
même pied de page, copiés dans chaque fichier. Pour changer un lien du menu, une adresse ou
un numéro : faites un « rechercher / remplacer » dans tous les fichiers .html.
Le menu « Nos services » s'ouvre au survol (ordinateur) ; sur mobile, ses liens sont affichés
directement dans le menu.
Chaque page service a sa FAQ et son bloc « application/ld+json » (données Google) : si vous
modifiez une question ou une réponse, modifiez-la aussi dans ce bloc, en haut du fichier.
Les chiffres de l'exemple de rachat (rachat-de-credit.html) sont fictifs et calculés :
gardez-les cohérents si vous les changez.
